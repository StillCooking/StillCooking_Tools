# Versions, support, and license

*Compatibility, the update procedure, how to report an issue, and the MIT license.*

The plugin is distributed as source under the MIT license, from a public GitHub repository:
**you have the full source**, you may keep it, change it and ship it, and an update is a
`git pull`.
