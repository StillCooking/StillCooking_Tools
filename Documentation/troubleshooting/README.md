# Troubleshooting

*Symptoms and their causes, the literal messages the plugin logs, and the diagnostic procedures.*

Find your symptom in Common problems first. The plugin logs to one category,
`LogStillCooking`, and most of what it can tell you is in that log — including, for the two
situations that look like a hang, a message that names the missing call.
