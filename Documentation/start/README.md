# Start here

*Installation of a source-distributed plugin, the first node in a graph, and three checks that the build is good.*

The plugin is distributed as source code and cloned straight into your project's `Plugins/`
directory. There is nothing to configure: no project settings, no `.uproject` entry, no tags to
register.

Start with Quick start for a working graph in five steps, then read Installation and
Verification if something did not go the way the quick start says it should.
